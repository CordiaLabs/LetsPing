# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.3] - 2026-02-28

### Changed
- Bump to 0.3.3 for coordinated LetsPing release. Uses `@letsping/sdk@0.3.3`.
- README and examples aligned with the new one hour evaluation and approval helper paths.

## [0.3.1] - 2026-02-28

### Changed
- Package renamed from unscoped `letsping` to `@letsping/cli`. Use `npx @letsping/cli demo` and `npx @letsping/cli dev`.

## [0.3.0] - 2026-02-28

### Changed
- Bump to 0.3.0 for coordinated LetsPing release. Requires `@letsping/sdk@0.3.0`.
- Compatibility: Node.js 18+.
- Supports `npx @letsping/cli demo` and local webhook tunnel for first-run experience.

## [0.2.1] - 2025-02

- CLI for localhost tunnel and webhook handling.
